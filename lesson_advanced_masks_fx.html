Paintstorm Studio — Advanced Masks, FX & Layers

🎨 Paintstorm 🎭 Masks ✨ FX

Masks and blend modes are how professionals add light, texture, and mood non-destructively. In this lesson you'll build compound masks, stack a light-FX pass with rim glow, and fold in photo texture at low opacity — all while keeping your darks clean and your mid-tones from turning to mud.

Goal: Build compound/stacked masks, add Screen/Add glow and Multiply shadow FX passes, refine mask edges, and integrate texture overlays through masks without muddying — so effects sit in the painting rather than on top of it.

Overview / How it works

A layer mask is a grayscale channel attached to a layer: white reveals the pixels, black hides them, gray partially reveals. Nothing is erased — you paint the mask, not the art, so every decision is reversible. A clipping layer is different: it confines a new layer's pixels to the non-transparent area of the layer directly beneath it. Both constrain where paint shows, but they answer different questions.

Compound masks come from stacking these tools: clip a shading layer to a base, then add a mask to that layer to fade the shading, and group the lot under a folder that carries its own mask. Each level narrows where paint can land, giving surgical control without a single destructive erase.

Blend modes for FX

Blend modes decide how a layer mathematically combines with what's beneath. A few carry most of the FX workload:

  • Screen / Add (Linear Dodge): brighten only — perfect for glow, light shafts, sparks, and rim light. Add is punchier and can blow out fast; Screen is gentler.
  • Multiply: darken only — ideal for shadow, ambient occlusion in crevices, and cast shadows. It never lightens, so it keeps shadow color coherent.
  • Overlay / Soft Light: contrast and texture — lighten the lights and darken the darks around 50% gray. Soft Light is the subtle sibling; use it to lay in texture and push local contrast.
Effects should look like they were lit or built into the scene, not stickered on top. Low opacity, a mask, and the right blend mode do that; a full-strength layer rarely does.

Hands-on practice

Start from a rendered form — a metal helmet, a fruit, any object with clear light and shadow. You'll add a shadow pass, a glow pass, a rim light, and a texture overlay, each masked.

  1. Group the base. Select your finished object layers and group them into a folder named Object. FX passes will clip or mask against this group.
  2. Shadow pass (Multiply). Add a new layer set to Multiply, clip it to the group. With a soft low-opacity brush in a desaturated cool tone, deepen the core shadows and contact shadows. Because it's Multiply, it only darkens — the hue stays consistent.
  3. Light-FX pass (Screen/Add). Add a layer set to Screen, clip it. Paint warm light where the key hits: top planes, highlights, the near edge of forms. Switch to Add only for the hottest speculars and pull opacity back so it glows rather than blows out.
  4. Rim / edge glow. New Screen layer, not clipped this time. Trace a thin bright line along the object's silhouette where a back light would catch it. Then add a mask to this layer and, with a soft black brush, knock the glow back everywhere except where the rim faces the light — that variation sells it.
  5. Refine mask edges. On any mask, blur it slightly for a soft transition, or run Levels on the mask to tighten a fuzzy edge into a crisp one. Painting white/black at low flow lets you feather reveals by hand.
  6. Texture overlay. Paste a photo texture (concrete, paper, hammered metal) above the object, set it to Overlay or Soft Light, and drop opacity to 15–35%. Add a mask and hide the texture off the object and out of the cleanest highlights so it reads as surface, not a decal.
  7. Guard the darks. Check your deepest shadows. If texture or FX has crept into them, mask it out — the darkest values should stay clean and near-neutral so the image keeps depth.
  8. Global glow FX (optional). Merge a copy to the top, blur it, set to Screen at low opacity for an atmospheric bloom. Mask it off faces you want to stay sharp.

✅ Tip: Name and color-code your FX layers (Shadow · Light · Rim · Texture · Bloom). When something looks off you'll know exactly which pass to dial back instead of hunting through a stack.

⚠️ Pitfall — muddy mid-tones: Overlay and Soft Light desaturate and gray toward the middle when stacked too heavily. If mid-tones go flat and lifeless, reduce texture opacity, mask it out of the mid-values, or add a touch of saturation back on a separate pass.

What you've learned

  • Layer masks control visibility with a grayscale channel; clipping layers borrow the alpha of the layer below — combine them for compound, surgical control.
  • Multiply darkens (shadow), Screen/Add lighten (glow, rim), Overlay/Soft Light add texture and contrast.
  • Build FX as separate, named passes: shadow, light, rim glow, texture, bloom — each masked so you can dial it back.
  • Integrate photo texture at low opacity through a mask so it reads as surface, not a decal.
  • Guard your darkest values and mid-tones from creeping FX to avoid mud and preserve depth.

✅ Carry it forward: The best FX are invisible as effects — they read as light, material, and atmosphere that were always there.
